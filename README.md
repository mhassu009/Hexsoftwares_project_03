# 📊 COVID-19 Global Data Analysis Dashboard (Excel)

## 📌 Project Overview
This project delivers an interactive Data Analysis Dashboard built in Microsoft Excel using global COVID-19 data. It provides key insights into total global cases, mortality rates, monthly infection trends, and top affected countries with dynamic continent-level filtering.

---

## 🛠️ Key Features & Tools Used
- *Pivot Tables & Pivot Charts:* Created dynamic summary tables and visual representations.
- *Interactive Slicers:* Added continent slicers connected to multiple charts for multi-level data filtering.
- *KPI Cards:* Showcased high-level metrics (Total Cases: *771M+, Total Deaths: **6.9M+*).
- *Data Visualizations:*
  - *Horizontal Bar Chart:* Top 10 countries ranked by COVID-19
